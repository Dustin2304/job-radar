BEWERTUNG VERSTEHEN

Gute Signale. Klare Einordnung.

Der Pre-Score (0–100 Punkte) ist die regelbasierte Vorbewertung aus deinem Repo. Er setzt sich aus Erfahrungslevel (25), Technologien (30), Rollensignalen (25) und Standort / Arbeitsmodell (20) zusammen.

Er ist eine Orientierung für deine Auswahl. Fehlende Informationen werden im Backend neutral bewertet.

Karriererichtungen und Kategorien kommen aus dem semantischen Matching. Ähnlichkeiten sind keine prozentuale Eignung und verändern den Pre-Score nicht.

Firmen-Watchlist zeigt die Markierung aus deinen importierten Daten. Die Merkliste ist deine persönliche Auswahl in diesem Browser.

Die LLM-Bewertung ist im geprüften Repo noch nicht in die Pipeline integriert; diese Oberfläche zeigt deshalb keine erfundenen KI-Empfehlungen.
